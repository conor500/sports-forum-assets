# Sports Forum assets

Public image host for The Sports Forum newsletter (Kit). Images are referenced by raw URL:
`https://raw.githubusercontent.com/conor500/sports-forum-assets/main/<path>`

- `email/charts/` chart images rendered from cited studies
- `email/photos/` photos used in issues

Keep files small (under 200KB, PNG/JPG, 1200px wide max) for fast loading and good deliverability.
